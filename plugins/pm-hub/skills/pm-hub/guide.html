PM 총괄 가이드

메인 세션 하나가 PM 이 되고, 일은 하위 세션들이 합니다. 나는 메인 세션과만 이야기하면 됩니다.

1한눈에 보기

2설치 (한 번만)

claude plugin marketplace add akokai79/pm-hub; claude plugin install pm-hub@pm-hub
방법이렇게
A. Claude 에게 맡기기 (가장 쉬움)Claude 세션에 이 명령 실행해서 설치해줘: 뒤에 위 한 줄을 붙여 보내기 → 허락 창이 뜨면 「허락」
B. 직접 실행위 한 줄을 PowerShell(또는 터미널)에 붙여 넣고 Enter
  1. A 나 B 로 설치
  2. Claude 데스크톱 앱을 껐다 켜기
  3. 새 세션에서 PM 총괄로 시작해줘 — 설치한 그 세션이 아니라 새로 연 세션부터 적용됩니다

A 에서 명령만 붙여 넣으면 Claude 가 설명만 하고 실행하지 않을 수 있습니다. 「실행해서 설치해줘」를 꼭 붙이세요.

처음에 「가성비 / 결과우선」 중 하나를 고르면 끝입니다. 새 버전 받기: claude plugin update pm-hub@pm-hub

5모델 고르는 기준

일 종류가성비결과우선
A 단순 (읽기 · 문구)haiku · lowsonnet · low
B 조사 · 문서sonnet · lowsonnet · medium
C 일반 개발sonnet · mediumopus · medium
D 위험 개발 (보안 · 결제 · DB)opus · mediumopus · high
E 설계 · 검수opus · mediumfable · high

표보다 높이지 않습니다. 같은 일이 두 번 실패할 때만 한 단계 올리고 알려 드립니다.

메인(PM) 세션 자신가성비결과우선
추천 모델 · 노력opus · mediumopus · high

하위 세션은 메인 세션보다 높은 모델을 못 씁니다. 메인을 sonnet 으로 두면 어려운 일도 sonnet 으로 내려가고, fable 로 두면 하루 종일 쌓이는 대화 사용량이 커집니다. 메인 세션 모델은 앱의 모델 선택에서 바꿉니다.

내 요금제에 없는 모델은 저절로 바꿔 씁니다: fable → opus, opus → sonnet, haiku → sonnet · low. 위험한 일에서 sonnet 까지 내려가야 하면 먼저 물어봅니다.

7총괄판 탭 3개

탭보이는 것갱신하려면
현황판맨 위 사용량 · 금액, 정하실 것, 업무 나무(할 일마다 마지막에 「AI 검수」 칸), 하위 세션, 할 일과 예상 시간, 용어집, 기록저절로 (PM 이 계속 갱신)
설정 한눈에CLAUDE.md 지침, 내 스킬, 플러그인, 훅(자동 실행), 권한 규칙, 메모리, 예약 작업. 비밀값은 ••• 로 가림. 「삭제 추천」 · 「추가 추천」 버튼설정
AI 통제 점검영역별 점검 질문, 충족 · 부분 충족 · 없음, 근거 메모, 다음 점검일 (점검 목록이 있는 경우). 「해결 솔루션 가이드」 버튼AI 통제 갱신

추천 버튼은 누를 때마다 내 Claude 사용량을 조금 씁니다(처음 한 번 허락 창이 뜹니다). 페이지는 아무것도 지우거나 바꾸지 않습니다. 마음에 드는 추천은 카드의 「PM 에게 보낼 말」을 복사해 메인 세션에 보내면, PM 이 검토하고 필요하면 선택창으로 물은 뒤 진행합니다.

할 일 목록의 마지막 단계는 늘 「AI 검수」입니다. 작업한 세션이 아닌 다른 세션이 확인하며, 첫 실측에서 검수 비용은 작업 비용의 약 7% 였습니다.
