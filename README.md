# PM 총괄 스킬 (pm-hub)

Claude Code 의 메인 세션 하나가 PM 이 되어 대화 · 일 나누기 · 확인 · 보고를 맡고, 실제 작업은 하위 세션들이 합니다.
사용자는 하위 세션을 따라다니지 않고, 메인 세션의 질문창과 총괄판만 보면 됩니다.

## 설치 (한 줄)

PowerShell 이나 터미널에 아래 한 줄을 붙여 넣고 실행합니다. 또는 Claude 세션에 「이 명령 실행해서 설치해줘:」 뒤에 붙여 보내면 Claude 가 대신 실행합니다.

```
claude plugin marketplace add akokai79/pm-hub; claude plugin install pm-hub@pm-hub
```

그다음 Claude 데스크톱 앱을 껐다 켜고, **새 세션**에서 「PM 총괄로 시작해줘」라고 말하면 됩니다.
처음 한 번은 본인 전용 총괄판(비공개 웹 페이지)을 만들고, 「가성비 / 결과우선」 중 진행 방식을 묻습니다.

업데이트: `claude plugin update pm-hub@pm-hub`

그림과 표로 된 가이드는 설치 뒤 메인 세션에 「가이드」라고 보내면 열어 줍니다. (원본: [guide.html](plugins/pm-hub/skills/pm-hub/guide.html))

## 필요한 것

- Claude 데스크톱 앱의 Code 탭 (하위 세션 만들기 · 보관 · 세션 목록은 데스크톱 앱 기능입니다)
- Claude Code 명령(`claude`)이 설치되어 있어야 합니다

## 들어 있는 기능

- 하위 세션의 질문을 PM 이 모아 질문창 하나로 묻기 (하위 세션은 질문창을 띄우지 않음)
- 총괄판: 정하실 것 · 업무 나무 · 하위 세션 표 · 할 일별 모델/노력 · 예상/실제 시간 · 용어집 · 최근 기록
- 「가성비 / 결과우선」에 따라 일 종류(A 단순 ~ E 설계·검수)별 하위 세션 모델 · 노력 자동 선택, 과하게 올리지 않는 상한
- 전문 용어마다 용어집 링크
- 끝난 하위 세션 자동 보관 (영구 삭제 아님)
- 다른 주제가 나오면 「여기서 / 새 세션 / 담당 세션」 묻기
- 의견을 주면 검토 · 보완 · 추가 제안 뒤 고르게 하기
- 할 일마다 작업 세션이 아닌 별도 검수 세션이 확인 (통과해야 「완료」, 반려면 작업 세션으로 되돌림)
- 「상세」라고만 보내면 지금 할 일을 더 쉽고 자세하게 다시 설명 (무엇을 · 어디서 · 어떻게 · 안 하면 · 걸리는 시간)
- 「할일」이라고만 보내면 내가 직접 해야 할 것만 급한 순서로 정리해 보여 주기
- 총괄판 맨 위에 쓴 토큰 · API 가격 환산 금액(원화) · CLI 로 했다면 아꼈을 추정치
- 총괄판 탭 3개: 현황판 · 설정 한눈에(CLAUDE.md · 스킬 · 훅 · 플러그인 · 권한 · 메모리, 비밀값 가림) · AI 통제 점검
- 할 일 목록 마지막 단계는 늘 「AI 검수」
- 모든 주소는 원클릭 링크, 모든 질문은 선택창
- 완료 근거 확인, 멈춤 · 오류 알림, 비용 위험 먼저 묻기, 결정 기록, 하루 요약

운영 배포 · 결제 · 영구 삭제 · 운영 DB 적용은 늘 먼저 묻도록 되어 있습니다.
